사무실에서는
이런 걸 지원해요

  • 퇴사자 계정 정리나간 직원이 가입했던 업무 서비스를 찾아 정리할 계정을 알려 드려요.
  • 사무실 전체 구독료누가 무엇을 얼마에 쓰는지, 다음 결제일까지 한 화면에 모아요.
  • 중복·안 쓰는 구독같은 서비스를 여러 명이 따로 결제하거나 아무도 안 쓰는 구독을 찾아요.
  • 보안 알림 모아 보기업무 계정의 새 기기 로그인, 비밀번호 변경 알림을 먼저 보여 드려요.
  • 근거 메일왜 정리해야 하는지 결제 영수증과 로그인 메일로 보여 드려요.
  • 정리 대행탈퇴, 해지, 비밀번호 변경은 에이전트가 대신하고 승인만 해요. 지금 개발 중이에요.

올해 12월, 사무실 3곳과 함께 파일럿을 진행해요. 우리 사무실도 해 보고 싶다면 편하게 물어봐 주세요.

이 브라우저에만 저장돼요

로그인 없이 쓰면 리포트 목록을 지금 쓰는 기기의 브라우저에만 저장해요.
이럴 때는 리포트를 다시 볼 수 없어요.

  • 방문 기록·쿠키·사이트 데이터를 지울 때
  • 다른 기기나 다른 브라우저에서 열 때
  • 시크릿·사생활 보호 창을 닫을 때

지금 이 브라우저는 저장을 막아 두었어요.
이 창을 닫으면 만든 리포트가 바로 사라져요.
