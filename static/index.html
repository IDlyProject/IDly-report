개발 중인 화면이에요

  1. 찾고

    메일 주소와 앱 비밀번호만 넣으면 돼요. 가입, 결제, 인증, 보안 메일을 골라 서비스별로 묶고, 애매한 곳은 AI가 한 번 더 판단해요.

    관리자 세팅도, 설치도 없이 이메일 하나로 시작해요.

  2. 보여주고

    보고서가 아니라, 오늘 결정할 일을 보여드려요. 구독, 보안 위험, 계정 수 순으로 지금 가장 중요한 하나를 첫 화면에 둬요.

    총 계정, 매달 나가는 구독료, 서비스별 다음 결제일, 보안 위험 계정, 안 쓰는 계정까지.

  3. 근거까지

    계정을 누르면 결제 영수증, 로그인 메일로 왜 그렇게 판단했는지 확인할 수 있어요. 믿고 바로 결정할 수 있게요.

    결제 메일 몇 번을 확인했는지, 마지막 메일이 언제였는지 함께 적어요.

  4. 대신 끝냅니다

    탈퇴와 해지는 에이전트가 내 브라우저에서 대신해요. 사용자는 승인만 하면 돼요.

    • 내 로그인 그대로로그인된 내 브라우저에서 진행하고, 비밀번호는 서버로 가지 않아요.
    • 중요한 순간엔 확정탈퇴, 결제 변경처럼 되돌릴 수 없는 동작 직전에 꼭 확인받아요.
    • 막히면 넘겨받기본인인증은 직접 하고, 모든 단계는 기록으로 남아요.
