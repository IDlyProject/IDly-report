자주 묻는 질문

앱 비밀번호가 뭐예요?

메일 서비스에서 외부 앱용으로 따로 만드는 비밀번호예요.
평소 로그인 비밀번호 대신 써요.
메일 연결 화면에 메일 주소를 넣으면 서비스별로 만드는 방법이 나와요.

메일 비밀번호나 메일 내용을 저장하나요?

아니요. 비밀번호는 분석하는 동안만 쓰고 저장하지 않아요.
메일 원문도 저장하지 않고, 찾은 계정 목록만 리포트로 남겨요.

분석이 끝나면 앱 비밀번호를 지워도 되나요?

네. 메일 서비스 보안 설정에서 앱 비밀번호를 지워도 만든 리포트는 그대로 남아요.
다시 분석할 때 새로 만들면 돼요.

결제는 어떻게 하나요?

전체 리포트는 메일함마다 을 한 번 결제해요.
결제한 메일함은 다시 분석해도 추가 결제 없이 열려요.
결제는 해외 결제 대행사 Lemon Squeezy가 처리해요.

환불되나요?

전체 리포트는 결제하면 바로 열리는 디지털 콘텐츠라, 열람 후 단순 변심 환불은 제한돼요.
분석이 잘못됐다면 문의해 주세요.

이 브라우저에만 저장돼요

로그인 없이 쓰면 리포트 목록을 지금 쓰는 기기의 브라우저에만 저장해요.
이럴 때는 리포트를 다시 볼 수 없어요.

  • 방문 기록·쿠키·사이트 데이터를 지울 때
  • 다른 기기나 다른 브라우저에서 열 때
  • 시크릿·사생활 보호 창을 닫을 때
  • 결제한 리포트도 똑같아요

지금 이 브라우저는 저장을 막아 두었어요.
이 창을 닫으면 만든 리포트가 바로 사라져요.

나중에 로그인하면 이 브라우저의 리포트를 계정으로 옮겨 드려요.
